# Dot 补丁接入 Catalog166 候选

Dot 交付的 48 个补丁从 `6fdce008` 完整重放，源码与交付树一致。以 Catalog166 实际配套的发布核查版本 `072e124` 为接入基线。应用候选覆盖原有公开接口、存量数据格式及数据库目录兼容性。原正式 Writer 的文件及目录标识单独保留在原版本，涉及应用与 Writer 共用文件时，Writer 由 `snapshot-index.json` 指到原文件。

## 本轮采用

| 补丁 | 当前入口和理由 |
| --- | --- |
| 0001、0022、0034 | 现有发布工具分块计算归档摘要、只排序一次，且失败时回收自己创建的残留目录。保留当前包格式、摘要和发出成功回执的顺序。 |
| 0002、0009、0020、0030 | 既有设置维护入口。提高写入后已授权搜索的单页大小，分类已删除时继续只读确认，恢复原有排序日志。仍沿用原权限和已发布接口。 |
| 0003、0004、0006、0010–0012、0016、0024、0038 | APP 的库存查询和导出。减少重复取数和组装，继续按已授权仓库读取同一数据库快照。页外坏数据应使整次请求失败，导出失败应完整报错。 |
| 0005、0007、0013、0018、0019、0028、0029、0039、0043 | APP 的销货和调拨列表、详情和报表。合计仍适用原筛选与权限，打印保留负行，已裁决厅显示正确，历史页码与无效链接可以恢复。 |
| 0031 | 按用户 2026-11-19 裁决，已核实的历史空厅草稿允许改备注和业务日期。保留封存来源、仓、厅、客户、金额、商品行和结算条件。 |
| 0008、0014、0015、0033、0040 | 现有商品媒体入口。同一版本只复用并发期间的已核验内容，各请求仍分别鉴权。断开连接时跳过无效读取。 |
| 0026、0027、0036 | 现有宿主关停、库存或商品粘贴、条码方案加载入口。保持原工作预算、现有通知方式和重试权限。 |

## 本轮保留

| 补丁 | 当前判断 |
| --- | --- |
| 0017、0025、0044、0048 | 新增设置按 ID 读取接口及其连带改动，需要核对独立授权与发布接口边界。当前候选保留既有读回通道。 |
| 0021、0032、0035、0041、0045、0046 | Dot 修改的是原仓库的发布脚本。T45 当前实际配套工具是另外冻结的一份。这些改动应对照现行入口逐项移植，重新核暂存、启动、回滚和 helper 准入。整包复验中现有 Boot 拒绝用例有差异。 |
| 0023 | EXACT26 证据标识确有不一致的风险。直接把创建器模块引入读回路径会改变当前源码打包闭包，且这条维护路径不阻塞只读上线。 |
| 0037、0042 | 改的是前置资料/离线证据清理与错误保留。当前计划已有隔离、冻结的资料和续跑入口，后续与生成器版本配套再验证。 |
| 0047 | 隔离 PostgreSQL 17.11 验证原子性，适合安装工具的后续改进。该补丁修改数据库约束的安装和回退 SQL，需按实际安装入口及冻结目录另核。 |

## 验证记录

- Node 24.21.0 的两套类型检查、后端编译、构建冒烟和生产前端合成配置构建通过。定向测试 473 通过，1 个 Linux 专项在 macOS 跳过。
- 整仓按相同测试清单独立顺序复验。原 Catalog166 核查分支 4,911 通过、29 失败，合并候选 4,930 通过、29 失败，两边失败用例相同，另各 1 跳过、1 TODO。旧发布契约生成检查在两个版本均返回 INVALID_RELEASE_NATIVE35_BOUNDARIES，待按现场入口核对。
- 历史空厅的日期、备注和保存回读有独立合成测试。隔离 PostgreSQL 17.11 核实导出游标的参数绑定、101 行顺序、EOF 和事务关闭。FIT 原子约束的 8 项隔离数据库断言通过，发布脚本、现场 DB 和只读上线仍按冻结版单独验证。

本分支用于本地候选和 Dot 的独立审查。当前库中的导入计划和 Writer 绑定以原正式回执为准，发布、独立恢复和真实运行仍由本地负责人验收。
